\## 三、实验原理

\### 1. 创建数据库

从 Microsoft SQL Server 创建一个新数据库及存储该数据库的文件，或从先前创建的数据库的文件中附加数据库。

语法：

```sql

Create Database 数据库名

&#x20;   \[ON \[Primary]<filespec> \[,...n]

&#x20;       \[,\[<filegroup> \[,...n]]]

&#x20;   \[LOG ON <filespec> \[,...n]]

&#x20;   ]

&#x20;   \[COLLATE 排序方式]

&#x20;   \[WITH <option> \[,...n]]

```



`<filespec>::=`

```sql

( Name = 逻辑名,

&#x20; Filename = 'OS 文件的路径及名字'

&#x20; \[, Size = 文件初始大小 ]

&#x20; \[, Maxsize = {最大值|UNLIMITED} ]

&#x20; \[, FileGrowth = 文件大小增量值]

)

```



`< filegroup >::=`

```text

&#x20;   Filegroup 文件组名 <filespec> \[,...n]

```



\### 2. 修改数据库

在 Microsoft SQL Server 数据库中添加或删除文件和文件组。也可用于更改文件和文件组的属性，例如更改文件的名称和大小。ALTER DATABASE 提供了更改数据库名称、文件组名称以及数据文件和日志文件的逻辑名称的能力。

语法：

```sql

Alter Database 数据库名

&#x20;   { Modify Name = 新数据库名

&#x20;   | Add File <filespec> \[,...n ] \[To Filegroup 文件组名]

&#x20;   | Add Log File <filespec> \[,...n ]

&#x20;   | Remove File 逻辑文件名

&#x20;   | Modify File <filespec>

&#x20;   | Add Filegroup 文件组名

&#x20;   | Remove Filegroup 文件组名

&#x20;   | Modify Filegroup 文件组名 {文件组属性 | Name = 新文件组名}

&#x20;   | SET <optionspec> \[,...n ] \[WITH <termination>]

&#x20;   | COLLATE 排序方式

&#x20;   }

```



`<filespec>::=`

```sql

( \[Name = 逻辑名 ]

&#x20; \[, Newname = 新逻辑名 ]

&#x20; \[, Filename = 'OS 文件的路径及名字' ]

&#x20; \[, Size = 文件大小 ]

&#x20; \[, Maxsize = {最大值|UNLIMITED} ]

&#x20; \[, FileGrowth = 文件大小增量值]

)

```



\### 3. 删除数据库

从 Microsoft SQL Server 删除一个或多个数据库。删除数据库将删除数据库所使用的数据库文件和磁盘文件。

语法：

```sql

Drop Database 数据库名 \[,...n]

```



\### 4. 与数据库有关的存储过程

(1) `sp\_helpdb \[数据库名]`

\*   不带参数“数据库名”，表示查看所有数据库信息

\*   带参数“数据库名”，表示查看指定数据库信息



(2) `sp\_renamedb 数据库旧名, 数据库新名`

\*   修改数据库名



\*\*注意：以上存储过程，需从 master 数据库中执行\*\*



\### 5. 创建表

语法：

```sql

Create table \[ 数据库名.\[模式名].|模式名.] 表名

&#x20;   ({< 列定义 >

&#x20;     |列名 AS 列计算表达式

&#x20;     |< 表级约束 >}

&#x20;     \[,...n ]

&#x20;   )

\[ ON { 文件组 | DEFAULT } ]



< 列定义 >::=<列名> <列类型>

&#x20;   \[COLLATE < 排序方式 >]

&#x20;   \[NULL | NOT NULL]

&#x20;   \[ \[Constraint 约束名] DEFAULT 常数表达式 ]

&#x20;   |\[IDENTITY \[(初值,步长)] \[NOT FOR REPLICATION]]

&#x20;   \[ROWGUIDCOL]

&#x20;   \[< 列级约束 >]\[,...n]



< 列级约束 >::=\[ Constraint 约束名 ]

&#x20;   {{ PRIMARY KEY | UNIQUE }

&#x20;       \[CLUSTERED | NONCLUSTERED]

&#x20;   |\[FOREIGN KEY]

&#x20;       REFERENCES 参照表 \[( 参照列)]

&#x20;       \[ON DELETE { CASCADE|NO ACTION|SET NULL|

&#x20;           SET DEFAULT } ]

&#x20;       \[ON UPDATE { CASCADE|NO ACTION|SET NULL|

&#x20;           SET DEFAULT } ]

&#x20;       \[NOT FOR REPLICATION]

&#x20;   |CHECK \[NOT FOR REPLICATION]

&#x20;       ( 逻辑表达式 )

&#x20;   }



< 表级约束 >::=\[ Constraint 约束名 ]

&#x20;   {{ PRIMARY KEY | UNIQUE }

&#x20;       \[CLUSTERED | NONCLUSTERED]

&#x20;       ( 列名 \[ASC|DESC] \[,...n ])

&#x20;   |FOREIGN KEY ( 列名 \[,...n ])

&#x20;       REFERENCES 参照表 \[( 参照列 \[,...n ])]

&#x20;       \[ON DELETE { CASCADE|NO ACTION|SET NULL|

&#x20;           SET DEFAULT } ]

&#x20;       \[ON UPDATE { CASCADE|NO ACTION|SET NULL|

&#x20;           SET DEFAULT } ]

&#x20;       \[NOT FOR REPLICATION]

&#x20;   |CHECK \[NOT FOR REPLICATION]

&#x20;       ( 逻辑表达式 )

&#x20;   }

```



\### 6. 修改表

通过更改、添加、除去列和约束，或者通过启用或禁用约束和触发器来更改表的定义。

语法：

```sql

Alter Table \[ 数据库名.\[模式名].|模式名.] 表名

&#x20;   { Alter Column 列名 { 新类型|\[NULL|NOT NULL]}

&#x20;       |Add {{<列定义> | 列名 AS 列计算表达式 } \[,...n ]

&#x20;       |\[ WITH CHECK | WITH NOCHECK]

&#x20;           ADD {< 表级约束 >} \[,...n ]}

&#x20;       |Drop {\[CONSTRAINT] 约束名 | COLUMN 列名 } \[,...n ]

&#x20;       |{ CHECK | NOCHECK }

&#x20;           CONSTRAINT { ALL| 约束名 \[,...n ] }

&#x20;       |{ ENABLE|DISABLE }

&#x20;           TRIGGER { ALL| 触发器名 \[,...n ] }

&#x20;   }

```

其中，`<列定义>`、`<表级约束>`与创建表同。



\### 7. 删除表

删除表定义及该表的所有数据、索引、触发器、约束和权限规范。任何引用已除去表的视图或存储过程必须通过 `DROP VIEW` 或 `DROP PROCEDURE` 语句显式除去。

语法：

```sql

Drop Table \[ 数据库名.\[模式名].|模式名.] 表名 \[,...n]

```



\### 8. 创建索引

为给定表或视图创建索引。

只有表或视图的所有者才能为表创建索引。表或视图的所有者可以随时创建索引，无论表中是否有数据。可以通过指定限定的数据库名称，为另一个数据库中的表或视图创建索引。

语法：

```sql

Create \[Unique] \[Clustered|NonClustered] Index <索引名> On

&#x20;   <表名 | 视图名> ( 列名 \[ASC|DESC] \[,...n ] )

```



\### 9. 删除索引

从当前数据库中删除一个或多个索引。`DROP INDEX` 语句不适用于通过定义 `PRIMARY KEY` 或 `UNIQUE` 约束创建的索引。

语法：

```sql

Drop Index 表名.索引名 | 视图名.索引名 \[,...n]

或 Drop Index 索引名 On <表名 | 视图名> \[,...n]

```

\## 实验二 SQL 查询语句实验

\### 一、实验目的

掌握各种形式的查询语句，加深对 SQL 查询语句的理解。

\### 二、实验环境

硬件：PC 机

软件：SQL Server 2019 及以上

\### 三、实验原理

\#### 1. SQL-92 查询命令简单的语句格式

语法：

```sql

Select \[All|Distinct] <目标列表达式> \[,...n]

From <表名或视图名> \[,...n]

\[Where <条件表达式>]

\[Group By <分组表达式> \[Having <条件表达式>] ]

\[Order By <排序表达式> \[ASC|DESC] ]

```

\#### 2. T-SQL 查询命令

从数据库中检索行，并允许从一个或多个表中选择一个或多个行或列。

(1) 基本语法

```sql

SELECT 查询列表 \[INTO 新表名]

FROM <表名>

\[WHERE 条件表达式]

\[GROUP BY 分组表达式

\[HAVING 组内数据条件表达式] ]

\[ORDER BY 排序表达式 \[ASC|DESC] ]

```

可以在查询之间使用 UNION 等运算将，以将查询的结果组合成单个结果集。

(2) SELECT 子句

指定由查询返回的列。

语法：

```sql

SELECT \[ALL|DISTINCT]

\[TOP n \[PERCENT] \[WITH TIES]]

<select\_list>

```
